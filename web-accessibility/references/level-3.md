# L3 품질마크 기준

이 파일은 **L3 품질마크** 기준이다. 다른 수준의 파일과 섞어 쓰지 않는다.

## 적용 기준

웹 접근성 자체가 목적인 작업에 씁니다. 품질마크 획득 여부와 관계없이 품질마크 수준의 완벽한 준수가 필요할 때입니다. 33개 항목에 예외가 없고, 필요하면 구조와 디자인도 바꿉니다.

## 작업 지시

1. 33개 항목을 모두 적용하며 "생략"이나 "해당 시"로 넘기지 않는다. 해당 기능이 없으면 "해당 없음"과 근거를 남긴다.
2. 기준을 충족하지 못하면 DOM 구조, 레이아웃, 디자인 변경까지 제안·수정한다.
3. 공통 영역(헤더, GNB, 푸터, 레이어 팝업)을 가장 먼저 처리한다.
4. 기본 상태뿐 아니라 오류, 빈 결과, 열림·닫힘, 로딩 등 모든 상태를 점검한다.
5. 첨부파일, 영상, 지도, 외부 위젯 등 직접 만들지 않은 콘텐츠도 대상에 포함한다.
6. 결과물은 항목별 판정(적합·부적합·해당 없음), 근거, 수정 코드를 함께 제시한다.

## 항목별 규칙

항목별로 판정 기준과 유형별 적용·구현을 정리했다. "적용"이 "조건부"이면 구현 칸의 조건을 따른다.

### 1.1.1 적절한 대체 텍스트 제공

판정 기준: 정보 손실 없음. 배너 문구 전체 기재

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 정보 이미지 | 준수 | `alt`에 이미지가 전달하는 내용을 씀. "이미지", "사진" 같은 요소 정보는 넣지 않음 | 정보 이미지: alt 누락, 파일명, alt="이미지" / 이모티콘 이미지: alt="이모티콘" / QR코드: alt="QR코드" / 캡차: alt에 정답 문자 기재 / 사용자가 올리는 이미지: 입력 수단 없음 |
| 장식 이미지 | 준수 | `alt=""` 또는 CSS `background-image` | alt="구분선" |
| 이미지 링크·버튼 | 준수 | `alt`에 목적지·기능을 씀("홈", "입사 지원서 PDF 다운로드"). 같은 제목 텍스트와 한 링크로 묶으면 이미지 `alt=""` | 이미지 링크·버튼: alt="더보기"처럼 기능을 알 수 없음 / 썸네일 + 같은 제목 텍스트: 이미지와 텍스트가 각각 같은 내용을 읽음 |
| 아이콘 폰트·SVG 아이콘 버튼 | 준수 | 아이콘은 `aria-hidden="true"`, 요소 안에 `.blind` 텍스트 또는 `aria-label`. 영어·약어는 한국어로 풀어 씀(new → 새 글) | 아이콘 폰트·SVG·빈 링크·빈 버튼: `<button></button>`, `<a class="menu"></a>` / 영어·약어 아이콘 텍스트: 영어 그대로 읽힘 |
| 텍스트가 들어간 배너 | 준수 | 이미지 속 문구 전체를 `alt`에. 길면 숨김 텍스트로 | 문구 일부만 기재 |
| `<input type="image">` | 준수 | `alt` 필수 | alt 누락 |
| 정보를 담은 인라인 SVG | 준수 | `<svg role="img" aria-labelledby="t"><title id="t">…</title>` |  |
| 이미지맵 `<area>` | 준수 | 영역마다 `alt` | alt 누락 |
| 차트·인포그래픽 | 준수 | 짧은 `alt` + 상세 내용을 데이터 표, 숨김 텍스트, `aria-describedby` 중 하나로 제공 | 수치 정보 누락 |
| CSS 배경으로 넣은 정보 이미지 | 준수 | 담긴 정보 전부 `.blind` 텍스트로 제공 | 배경 이미지 정보가 보조기술에 전달 안 됨 |

### 1.3.1 표의 구성

판정 기준: 모든 셀이 제목 셀과 연결

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 단순 데이터 표 | 준수 | `<caption>`에 표 제목, 열 제목은 `<th scope="col">` | 표 정보(제목·요약): caption 누락 / 열 제목: 제목 셀을 `<td>`로 / 반응형으로 바뀌는 표: 제목 셀 숨김으로 값만 남음 |
| 행·열 제목이 모두 있는 표 | 준수 | 행 제목은 `<th scope="row">` | 행 제목 미구분 |
| 레이아웃용 표 | 준수 | 사용하지 않음. 불가피하면 `th`·`caption`·`summary` 없이 `role="presentation"` | 레이아웃 표에 th 사용 |
| 병합 셀이 있는 복잡한 표 | 준수 | `scope="colgroup"`·`"rowgroup"` 또는 `th`의 `id`와 `td`의 `headers` 연결 | 병합 셀과 데이터 연결 끊김 |
| 표 구조 요약 | 준수 | `<caption>` 안 요약 문장 또는 `aria-describedby` |  |
| `div`로 만든 표 형태 목록 | 준수 | `<table>`로 재작성(불가하면 `role="table"`·`row`·`columnheader`·`cell`) | 시각적 표가 구조 정보 없음 |

### 1.3.2 콘텐츠의 선형구조

판정 기준: CSS 해제 시 전체 순서 논리적

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 본문 읽는 순서 | 준수 | 스타일을 끈 상태에서도 읽는 순서가 논리적(DOM 순서 = 시각 순서) | 문서 순서: CSS 해제 시 순서 뒤섞임 / 세로쓰기 등 시각 표현: 글자 단위로 쪼개져 의미 없음 |
| 숨김 텍스트 위치 | 준수 | `.blind` 텍스트는 대상 요소 안 또는 바로 옆 | 숨김 텍스트가 엉뚱한 위치에서 읽힘 |
| 탭·아코디언 패널 위치 | 준수 | 패널을 트리거 바로 뒤에 두거나 `aria-controls` 연결 | 탭 목록 뒤에 패널이 몰려 있음 |
| CSS로 바꾼 순서(`order`, `row-reverse`, `position`) | 준수 | 전부 DOM 재배치 | 제목이 본문보다 뒤에 읽힘 |
| 레이어 팝업 DOM 위치 | 준수 | 트리거 직후 삽입 또는 모달 패턴 완전 구현 | 팝업이 body 끝에 있고 초점 이동 없음 |

### 1.3.3 명확한 지시사항 제공

판정 기준: 예외 없음

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 모양·위치 지시("오른쪽 버튼") | 준수 | 실제 명칭으로 지칭: "[다음] 버튼을 누르세요" | "동그란 버튼", "오른쪽 버튼" |
| 색 지시("빨간 항목은 필수") | 준수 | 색과 함께 텍스트·기호 병기("필수") | "빨간 항목은 필수입니다" |
| 소리만으로 하는 안내 | 준수 | 비프음 등 소리 안내와 함께 시각적 안내(텍스트) 병행 | 정답·오답을 소리로만 알림 |
| 필수 입력 `*` 표시 | 준수 | 기호 의미를 폼 상단에 안내 + `required` 또는 숨김 텍스트 "필수" | *만 표시 |

### 1.4.1 색에 무관한 콘텐츠 인식

판정 기준: 색 구분 요소 전수

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 입력 오류 상태 | 준수 | 색 + 오류 문구·아이콘·"필수" 텍스트 | 빨간 테두리만 |
| 선택된 탭·메뉴·페이지 | 준수 | 색 + 굵기·밑줄·테두리·아이콘, `aria-selected`·`aria-current` | 활성 탭을 색으로만 구분 |
| 상태 배지(승인, 반려 등) | 준수 | 텍스트로 상태 표기(승인, 반려, 품절) | 색 점만 표시 |

### 1.4.3 텍스트 콘텐츠의 명도 대비

판정 기준: 비활성 요소 외 전수

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 본문 텍스트 | 준수 | 4.5:1 이상 | 회색 안내 문구(#999 계열) |
| 버튼·링크·입력 텍스트 | 준수 | 4.5:1 이상. hover 등 모든 상태에서 충족 | placeholder, 입력값, 링크·버튼 텍스트: 연한 placeholder / 상태별 텍스트(hover, 비활성 아님): hover 시 대비 저하 |
| 큰 텍스트(18pt, 굵은 14pt 이상) | 준수 | 3:1 이상(화면 확대가 가능한 텍스트 콘텐츠도 3:1까지) |  |
| `placeholder` | 준수 | 4.5:1 | 연한 placeholder |
| 이미지 안 텍스트 | 준수 | 전부 4.5:1(이미지 속 글자도 같은 기준) | 배경 사진 위 흰 글자 |

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 인접 목록·카드 | 준수 | 테두리, 구분선, 배경색 명도 차이 중 하나 이상. 인접 버튼·링크는 충분한 간격(터치 환경 포함) | 목록·카드·게시물: 경계 없이 붙은 목록 / 인접 버튼·링크: 링크가 붙어 있어 구분 불가 |

### 2.1.1 키보드 사용 보장

판정 기준: 키보드로 못 하는 기능 없음

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 링크·버튼 | 준수 | 이동은 `<a href>`, 동작은 `<button type="button">`. 키 처리는 `keydown`에서(`keypress` 의존 지양) | 링크·버튼: `<div onclick>`, `<a>`에 href 없음 / 키보드 이벤트 처리: 키 처리 누락 |
| `div`·`span` 클릭 요소 | 준수 | `<button>`으로 교체. 불가하면 `role="button" tabindex="0"` + Enter·Space 처리 | 마우스 이벤트만 연결 |
| 키보드 트랩 | 준수 | 에디터·iframe·플러그인·모달에서 키보드로 진입·조작하고 Tab 또는 Esc로 빠져나올 수 있게 | 진입 후 조작 불가 |
| 마우스오버 전용 서브메뉴 | 준수 | `focus`·`focusin`이나 `:focus-within`으로 같은 동작(서브메뉴, 툴팁) | hover로만 열림 |
| 커스텀 셀렉트·체크박스·라디오 | 준수 | 네이티브 `input`을 유지하고 시각적으로만 감춤(`opacity: 0`). `display: none`·`visibility: hidden` 금지 | 원본 input 제거로 초점 불가 |
| 드래그 앤 드롭 | 준수 | 버튼이나 방향키로 같은 결과(위로·아래로 버튼 등) | 드래그로만 조작 |
| 지도·캔버스 | 준수 | 키보드 컨트롤 또는 같은 정보의 텍스트 대안 |  |

### 2.1.2 초점 이동과 표시

판정 기준: 초점 손실·순서 역전 없음

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 초점 표시 | 준수 | `:focus-visible`에 테두리·배경 변화(`outline: 2px solid; outline-offset: 2px`). `outline: none` 단독 금지, 표시에 시간제한 없음 | outline: none 후 대체 스타일 없음 |
| 초점 순서 | 준수 | 관례·의미 순서와 일치(아이디 → 비밀번호 → 로그인)하도록 DOM 순서로 해결, 양수 `tabindex` 금지. 모든 요소에서 다음·이전으로 이동 가능, 초점만으로 페이지 전환 금지 | 초점 순서: 아이디 → 로그인 → 비밀번호 / 키보드 함정: 에디터·동영상 플레이어에 갇힘 / 갑작스러운 전환: 초점 받으면 페이지 이동 |
| 화면에서 숨긴 요소 | 준수 | `hidden`·`display: none`·`inert`, 비활성 슬라이드 내부 링크 `tabindex="-1"` | 닫힌 메뉴·비활성 슬라이드 안 링크에 초점 |

### 3.3.1 오류 정정

판정 기준: 모든 폼·모든 오류 유형

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 필드별 오류 문구 | 준수 | 오류 문구를 `aria-describedby`로 필드에 연결 + `aria-invalid="true"`. 어떤 항목이 왜 틀렸는지("생년월일은 숫자 8자리로 입력하세요")와 올바른 형식 예시 제시 | 오류 메시지 연결: 메시지가 필드와 무관하게 표시 / 오류 위치·이유 안내: "입력값을 확인하세요"만 표시 / 수정 방법 제시: 형식 안내 없음 |
| 오류 시 입력값 유지 | 준수 | 제출 실패해도 입력값 보존(비밀번호 제외 가능) | 오류 시 전부 초기화 |
| 제출 시 오류 안내 | 준수 | + 상단 오류 요약 `role="alert"` | 오류 표시만 하고 초점은 제출 버튼 |
| 실시간 입력 검증 | 준수 | 결과 문구를 `aria-live="polite"` 영역에 | 시각 표시만 |
| 결제·삭제 등 중요 처리 | 준수 | 확인·취소 단계 전부 |  |

### 3.3.2 레이블 제공

판정 기준: 예외 없음

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 텍스트 입력 | 준수 | `<label for="id">`와 `id` 연결, 또는 `<label>`로 감싸기. 형식·조건 안내는 `aria-describedby`로 연결, 커스텀 입력은 `aria-labelledby` | 텍스트 입력·셀렉트·텍스트 영역: 레이블이 텍스트로만 있고 연결 없음 / 입력 형식·조건 안내: 안내가 입력란과 분리 / 커스텀 입력 컴포넌트: 네임 없음 |
| 레이블이 안 보이는 입력(검색창) | 준수 | 숨김 `<label>`, `title`, `aria-label`, `aria-labelledby` 중 하나 | placeholder만 |
| `placeholder`만 있는 입력 | 준수 | 사용 금지, 레이블 추가 |  |
| 라디오·체크박스 그룹 | 준수 | 각 항목 `<label>` + 그룹은 `<fieldset>`·`<legend>` | 그룹 질문이 연결되지 않음 |
| 여러 칸 입력(전화번호, 생년월일) | 준수 | 칸마다 `title` 또는 숨김 레이블("휴대폰 앞자리") | 첫 칸만 레이블 |
| 필수 입력 | 준수 | `required`·`aria-required` 또는 레이블에 "필수" | 시각 기호만 |
| 필터·정렬 등 숨은 입력 | 준수 | 모두 레이블 |  |

### 3.3.3 접근 가능한 인증

판정 기준: 인지 테스트만 요구하지 않음

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 비밀번호 붙여넣기·자동완성 | 준수 | `paste` 차단 금지, `autocomplete="username"`·`"current-password"`, OTP는 `autocomplete="one-time-code"`와 붙여넣기 허용 | 아이디·비밀번호: onpaste 차단, autocomplete="off" / 인증번호(OTP): 칸마다 직접 입력 강요 |
| 이미지 캡차 | 준수 | 음성 캡차 또는 다른 인증 수단 병행 | 대안 없는 이미지 퀴즈 |
| 퍼즐·계산형 인증 | 준수 | 인지 테스트가 없는 대안(소셜 로그인, 생체 인증, 휴대폰·USB 소지 인증 등) | 비밀번호만 |

### 3.3.4 반복 입력 정보

판정 기준: 재입력 요구 없음

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 개인정보 입력 필드 | 준수 | `autocomplete`: `name`·`email`·`tel`·`postal-code`·`street-address` 등 | autocomplete 누락 |
| 다단계 폼의 이전 입력값 | 준수 | 이전 단계 값 자동 채움 또는 선택 목록 전부 | 주문자·수령자 정보: 같은 주소 재입력 / 다단계 폼: 단계마다 이름·연락처 재입력 |

### 4.1.1 마크업 오류 방지

판정 기준: 중복 속성·중첩 오류 포함

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 중복 `id` | 준수 | 문서 안 `id` 유일. 반복 컴포넌트·동적 삽입은 고유 접미사 | 같은 id가 목록마다 반복 |
| 열고 닫기·중첩 오류 | 준수 | 시작·끝 태그 짝 맞춤(`</div>` 누락 금지), `<a>` 안 `<button>`·`<p>` 안 `<div>` 같은 잘못된 중첩 금지 | 요소의 열고 닫음: `</div>` 누락 / 요소의 중첩: `<b><i></b></i>`, `<a>` 안 `<button>`, `<p>` 안 `<div>` |
| 중복 속성 | 준수 | 한 요소에 같은 속성 두 번 금지 | class를 두 번 선언 |
| 문법 오류 전체 | 준수 | W3C Markup Validator 오류 0건 |  |

### 4.2.1 웹 애플리케이션 접근성 준수

판정 기준: 이름·역할·상태·값 전달

| 유형 | 적용 | 구현 | 대표 오류 |
|---|---|---|---|
| 네이티브 요소 우선 | 준수 | `<button>`·`<a>`·`<input>`·`<select>`·`<details>`·`<dialog>`로 되면 ARIA를 쓰지 않음. 네이티브 의미를 덮지 않고, 초점 받는 요소에 `aria-hidden="true"` 금지 | 네이티브 요소 우선: div로 만든 버튼·체크박스 / ARIA 사용 규칙: 숨긴 요소가 초점 받음 |
| 토글·펼침 상태 | 준수 | `role` + 접근 가능한 이름 + 상태 속성(`aria-expanded`·`aria-pressed`·`aria-checked`)을 스크립트로 갱신 | 시각 상태만 바뀌고 속성 미갱신 |
| 탭 | 준수 | + 방향키·Home·End, 선택 탭만 `tabindex="0"` |  |
| 모달 | 준수 | + Tab 순환 제한, 배경 `inert`, 초점 복귀 |  |
| 아코디언 | 준수 | `<button aria-expanded aria-controls>` |  |
| 캐러셀 | 준수 | + 현재 위치 텍스트, 초점 시 자동 정지 |  |
| 드롭다운·메뉴 버튼 | 준수 | + `aria-haspopup`, 방향키 탐색 |  |
| 콤보박스·자동완성 | 준수 | `role="combobox"`, `aria-activedescendant`, 결과 수 안내 |  |
| 상태 메시지(저장됨, 담김) | 준수 | `role="status"`, 긴급은 `role="alert"` | "장바구니에 담김"이 안 읽힘 |
| 로딩 상태 | 준수 | `aria-busy="true"`, 완료 시 상태 메시지 | 로딩 상태 미전달 |
| 외부 위젯·플러그인 | 준수 | 접근 불가하면 대체 수단(텍스트, 링크) 제공 | 접근 불가 지도·채팅 위젯 |

## 놓치기 쉬운 영역

| 영역 | 처리 |
|---|---|
| PDF·HWP 첨부 | 접근 가능한 문서로 변환하거나 같은 내용의 HTML 제공 |
