웹 접근성 품질마크(인증)

품질마크는 KWCAG 2.2 준수 여부를 과기정통부 지정 인증기관이 3단계로 심사해 부여하는 인증이며, 유효기간은 1년입니다.

구분 내용
주관 과학기술정보통신부
법적 근거 지능정보화 기본법 제47조제1항, 같은 법 시행규칙 제9조제5항
인증기관 과기정통부 지정 기관. 2026년 현재 게시 예: 한국웹접근성인증평가원, 웹와치, 한국디지털접근성진흥원
심사기준 KWCAG 2.2에 기초한 품질마크 인증기준(운영지침·심사지침)
심사 절차 사전(서면)심사 → 전문가심사 → 사용자심사
유효기간 인증일로부터 1년
인증범위 사이트 단위(예: 대표 홈페이지), 인증서에 범위 명시

출처: 서울시 웹 접근성 안내 (새 창 열림), 문화포털 품질마크 안내 (새 창 열림). 합격 점수, 수수료, 표본 페이지 수는 인증기관 공지를 확인해야 합니다.

심사 단계별 대비:

단계 심사 관점 미리 할 일
사전(서면)심사 신청 범위, 자동 점검 결과, 기본 오류 대상 URL 목록 정리, 자동 점검 도구로 오류 0건
전문가심사 표본 페이지의 33개 항목 수동 판정 33개 항목 자체 판정, 공통 영역·템플릿 우선 수정
사용자심사 장애인 사용자의 실제 과업 수행 스크린리더·키보드로 핵심 과업(가입, 검색, 신청, 결제) 완료 테스트

사전 자체 점검 절차:

  1. 인증 범위와 페이지 유형(메인, 목록, 상세, 폼, 팝업)을 정합니다.
  2. 헤더, GNB, 푸터, 레이어 팝업 등 공통 영역을 먼저 고칩니다.
  3. 페이지 유형별 대표 페이지로 33개 항목을 판정합니다.
  4. 오류 상태, 빈 결과, 모달 열림, 탭 전환 등 동적 상태까지 확인합니다.
  5. PDF, 영상, 지도, 외부 위젯을 확인합니다.
  6. 핵심 과업을 스크린리더와 키보드로 끝까지 수행합니다.
  7. 수정 후 같은 표본으로 재판정하고 보고서로 남깁니다.
