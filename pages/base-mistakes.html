참고사항

자주 지적받는 실수와 검증 도구

인증 심사에서 자주 지적되는 실수는 대부분 초점, 대체 텍스트, 레이블 세 가지에 몰려 있습니다.

실수 고치는 법
outline: none으로 초점 표시 제거 :focus-visible 스타일 제공
alt="이미지", alt="배너"처럼 무의미한 대체 텍스트 이미지가 전달하는 내용을 씀
이미지 안에 긴 텍스트(배너 문구) alt에 같은 문구 전체 기재 또는 본문 텍스트로 제공
placeholder만 있는 입력 필드 <label> 추가, 시각적으로 숨기려면 .blind
"더보기"가 여러 개인데 구분 불가 숨김 텍스트로 대상 명시
클릭 이벤트만 있는 <div>, <span> <button>으로 교체
모달 뒤 배경으로 초점이 빠져나감 초점 가두기 + 배경에 inert 속성
탭·아코디언 상태 속성 미갱신 스크립트에서 aria-selected·aria-expanded 함께 변경
헤딩을 글자 크기 맞추려고 아무 단계나 사용 구조 순서대로 쓰고 크기는 CSS로 조정

검증 도구:

  • 자동 점검: axe DevTools, WAVE, Lighthouse, 브라우저 개발자 도구의 접근성 트리
  • 명도 대비: Colour Contrast Analyser, 개발자 도구 색상 선택기
  • 마크업: W3C Markup Validation Service
  • 스크린리더 실사용: NVDA, 센스리더(Windows), VoiceOver(macOS·iOS), TalkBack(Android)

자동 도구는 일부 항목만 잡아내므로, 키보드 조작과 스크린리더 확인은 직접 해야 합니다.
