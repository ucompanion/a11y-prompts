참고사항

웹접근성 스킬 가이드

웹접근성 퍼블리싱 스킬이 무엇을 하고, 요청에 따라 어떻게 동작하는지 정리한 가이드입니다. 등록 예정인 스킬의 설계 기준이며, 스킬이 다루는 범위는 실무 체크리스트의 L1·L2·L3와 컴포넌트별 체크리스트이며, 이 문서들이 스킬의 참조 파일이 됩니다.

하는 일

퍼블리싱·마크업 작업에서 요청에 맞는 접근성 수준(L1~L3)의 기준을 골라 적용합니다. 수준은 한 번에 하나만 적용합니다.

동작 순서

단계 하는 일 읽는 파일
1. 요청 확인접근성·퍼블리싱 요청이면 스킬이 켜짐SKILL.md
2. 수준 결정요청에 수준이 있으면 그대로, 없으면 키워드로 판단, 그래도 애매하면 L1SKILL.md
3. 기준 읽기결정된 수준의 항목별 규칙(유형·적용·구현) 하나만 읽음level-1·2·3 중 하나
4. 컴포넌트 확인L2부터 반영: 탭, 모달 같은 커스텀 컴포넌트를 만들 때 읽음(L1은 기준으로 지정하지 않으며, 클로드가 알아서 처리)components
5. 작업기준에 따라 마크업·코드 작성

수준 결정 기준

수준 이런 요청 판단 키워드
L1 기본 준수일반 웹사이트 퍼블리싱, 시안 반영. 수준이 없을 때의 기본값퍼블리싱, 마크업, 기본
L2 전문 준수접근성 요구가 높은 웹사이트접근성 전체, ARIA, 스크린리더
L3 품질마크웹 접근성 자체가 목적인 작업인증, 품질마크, 완벽 준수

애매할 때는 낮은 수준으로 시작하고, 필요하면 한 단계씩 올립니다.

요청 예시

이렇게 요청하면 적용 수준 읽는 파일
"공지사항 페이지 퍼블리싱해줘"L1(지시 없음)level-1
"스크린리더까지 고려해서 모달 만들어줘"L2level-2, components
"품질마크 인증 목표로 검수해줘"L3level-3, components
"L2 기준으로 이 마크업 고쳐줘"L2(명시한 수준 우선)level-2

파일 구성

파일 내용
SKILL.md언제 쓰는지, 수준 결정 규칙, 어떤 파일을 읽을지
level-1·2·3수준별 항목별 규칙(항목, 판정 기준, 유형별 적용·구현)
components컴포넌트별 필수 마크업과 키보드·초점 동작(L2부터 적용, level-2·3 파일에서 참조)

알아둘 점

  • 수준 파일은 하나만 읽습니다. 여러 수준을 한꺼번에 읽으면 기준이 섞이고 읽는 분량도 늘어납니다.
  • 요청에 수준이 명시되면 키워드 판단보다 명시한 수준을 우선합니다.
