원칙 2. 운용의 용이성

마우스 없이 키보드만으로, 또는 터치·음성으로도 모든 기능을 쓸 수 있어야 합니다. 검사항목이 15개로 가장 많고, 퍼블리싱 오류도 가장 많이 나는 영역입니다.

지침 검사항목 퍼블리싱 규칙
2.1 입력장치 접근성 2.1.1 키보드 사용 보장 클릭 가능한 요소는 <a>, <button> 사용. <div onclick>이면 tabindex="0", role, Enter·Space 처리 추가
2.1 입력장치 접근성 2.1.2 초점 이동과 표시 초점 순서가 논리적이어야 함. outline: none 단독 사용 금지, :focus-visible로 대체 스타일 제공
2.1 입력장치 접근성 2.1.3 조작 가능 터치 대상은 대각선 6mm 이상(약 44×44px 권장), 대상 간 간격 확보
2.1 입력장치 접근성 2.1.4 문자 단축키 단일 문자 단축키는 끄기, 변경, 초점 있을 때만 동작 중 하나 제공
2.2 충분한 시간 제공 2.2.1 응답시간 조절 세션 만료 등 시간 제한은 미리 알리고 연장 수단 제공
2.2 충분한 시간 제공 2.2.2 정지 기능 제공 자동 슬라이드·움직이는 콘텐츠에 정지·이전·다음 버튼 제공
2.3 광과민성 발작 예방 2.3.1 깜빡임과 번쩍임 사용 제한 초당 3~50회 깜빡이는 콘텐츠 사용 금지
2.4 쉬운 내비게이션 2.4.1 반복 영역 건너뛰기 페이지 최상단에 "본문 바로가기" 링크 제공
2.4 쉬운 내비게이션 2.4.2 제목 제공 페이지 <title>, 프레임 title, 콘텐츠 블록 <h1>~<h6> 제공. 팝업·탭 전환 시 제목도 갱신
2.4 쉬운 내비게이션 2.4.3 적절한 링크 텍스트 "더보기", "여기"만 쓰지 않음. 숨김 텍스트로 "공지사항 더보기"처럼 목적 보완
2.4 쉬운 내비게이션 2.4.4 고정된 참조 위치 정보 전자책·PDF 등은 원본 쪽 번호 같은 위치 정보 유지
2.5 입력 방식 2.5.1 단일 포인터 입력 지원 핀치, 스와이프, 드래그 기능은 버튼 클릭 같은 단일 포인터 대안 제공
2.5 입력 방식 2.5.2 포인터 입력 취소 기능은 누를 때가 아니라 뗄 때(click, pointerup) 실행
2.5 입력 방식 2.5.3 레이블과 네임 화면에 보이는 버튼 텍스트가 접근 가능한 이름에 포함돼야 함
2.5 입력 방식 2.5.4 동작기반 작동 흔들기·기울이기 기능은 UI 대안과 끄기 수단 제공

건너뛰기 링크와 초점 스타일 예시:

<a href="#content" class="skip">본문 바로가기</a>
...
<main id="content" tabindex="-1">...</main>

.skip { position: absolute; left: -9999px; }
.skip:focus { left: 0; top: 0; z-index: 1000; }
:focus-visible { outline: 2px solid #1a73e8; outline-offset: 2px; }

화면에는 숨기고 스크린리더에만 읽히는 텍스트(링크 목적 보완용):

.blind {
  position: absolute; width: 1px; height: 1px;
  margin: -1px; overflow: hidden;
  clip: rect(0 0 0 0); clip-path: inset(50%);
  white-space: nowrap; border: 0;
}

<a href="/notice">더보기<span class="blind"> 공지사항</span></a>

display: none이나 visibility: hidden은 스크린리더에서도 읽히지 않으므로 이 용도로 쓰지 않습니다.
