원칙 3. 이해의 용이성

사용자가 예상하지 못한 화면 변화 없이, 입력과 오류를 이해하고 고칠 수 있어야 합니다.

지침 검사항목 퍼블리싱 규칙
3.1 가독성 3.1.1 기본 언어 표시 <html lang="ko"> 지정. 다른 언어 구간은 lang="en" 등으로 표시
3.2 예측 가능성 3.2.1 사용자 요구에 따른 실행 초점·값 변경만으로 페이지 이동이나 새 창 열기 금지. 새 창은 "새 창 열림"을 title 또는 숨김 텍스트로 안내
3.2 예측 가능성 3.2.2 찾기 쉬운 도움 정보 고객센터·도움말 링크를 모든 페이지의 같은 위치·순서에 배치
3.3 입력 도움 3.3.1 오류 정정 오류 위치와 원인을 텍스트로 알리고 수정 방법 안내. 입력값 유지
3.3 입력 도움 3.3.2 레이블 제공 모든 입력 요소에 <label for> 또는 aria-label. placeholder만으로 대체 금지
3.3 입력 도움 3.3.3 접근 가능한 인증 캡차·퍼즐 등 인지 테스트만 요구하지 않음. 붙여넣기·비밀번호 관리자 허용
3.3 입력 도움 3.3.4 반복 입력 정보 같은 과정에서 이미 입력한 정보는 자동 채움 또는 선택 제공

폼 레이블·오류 안내 예시:

<label for="email">이메일 <span aria-hidden="true">*</span><span class="blind">필수</span></label>
<input id="email" type="email" autocomplete="email"
       aria-describedby="email-error" aria-invalid="true">
<p id="email-error" role="alert">이메일 형식이 올바르지 않습니다. 예: name@example.com</p>

새 창 링크 예시:

<a href="https://example.com" target="_blank" rel="noopener">이용약관<span class="blind"> (새 창 열림)</span></a>
