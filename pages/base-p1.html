원칙 1. 인식의 용이성

화면을 보지 못하거나 색을 구분하기 어려운 사용자도 모든 정보를 받을 수 있어야 합니다.

지침 검사항목 퍼블리싱 규칙
1.1 대체 텍스트 1.1.1 적절한 대체 텍스트 제공 의미 있는 이미지는 alt에 내용·기능을 씀. 장식 이미지는 alt="" 또는 CSS 배경. 이미지 링크·버튼은 목적지나 기능을 씀
1.2 멀티미디어 대체 수단 1.2.1 자막 제공 음성이 있는 영상은 자막, 원고 또는 수어 제공
1.3 적응성 1.3.1 표의 구성 데이터 표에 <caption>, <th>, scope 제공. 레이아웃용 표 금지
1.3 적응성 1.3.2 콘텐츠의 선형구조 DOM 순서 = 읽는 순서. CSS로 시각 순서만 바꾸지 않음
1.3 적응성 1.3.3 명확한 지시사항 제공 "오른쪽 빨간 버튼"처럼 모양·위치·색만으로 안내하지 않음
1.4 명료성 1.4.1 색에 무관한 콘텐츠 인식 오류, 선택 상태, 그래프 범례를 색 외에 텍스트·아이콘·패턴으로도 표시
1.4 명료성 1.4.2 자동 재생 금지 소리는 자동 재생하지 않음. 불가피하면 3초 이내 정지 또는 정지 버튼 제공
1.4 명료성 1.4.3 텍스트 콘텐츠의 명도 대비 일반 텍스트 4.5:1 이상, 큰 텍스트(18pt 또는 굵은 14pt 이상) 3:1 이상
1.4 명료성 1.4.4 콘텐츠 간의 구분 테두리, 여백, 배경색 등으로 인접 콘텐츠를 구분

대체 텍스트 예시:

<!-- 정보 이미지 -->
<img src="chart.png" alt="2026년 3분기 매출 120억 원, 전년 대비 15% 증가">
<!-- 장식 이미지 -->
<img src="deco.png" alt="">
<!-- 아이콘 버튼 -->
<button type="button"><img src="close.svg" alt="팝업 닫기"></button>
